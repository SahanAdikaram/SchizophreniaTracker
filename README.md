# SchizophreniaTracker
Schizophrenia Tracker – currently in development.

To run this application run *npm start* in the terminal

This setup launches both the backend server and the client development environment.

*This prototype webcam-based screening tool analyzes eye movement patterns (pupil response, gaze stability, and tracking ability) to detect potential early signs of schizophrenia. Using computer vision (OpenCV/MediaPipe) and machine learning (scikit-learn), the system processes real-time video to generate a preliminary risk assessment, displaying results through intuitive visual feedback. Currently under development, this research-focused prototype demonstrates the feasibility of using consumer hardware for accessible mental health screening while maintaining local data processing for privacy. The tool represents an experimental first step toward objective, non-invasive schizophrenia risk assessment through ocular biomarkers, with future clinical validation planned as development progresses.*
