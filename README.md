SchizophreniaTracker: Early Detection Through Eye Tracking and AI

SchizophreniaTracker is an innovative tool that leverages webcam-based eye tracking and AI to detect early signs of schizophrenia. By analyzing clinically validated biomarkers, such as pupil reactions, gaze stability, and eye movement patterns—the system provides a quick, non-invasive risk assessment in just 5 minutes. Designed for accessibility, it transforms ordinary hardware into a powerful screening tool, offering real-time visual feedback and actionable insights for clinicians, caregivers, or individuals.

How to Run:

Clone the repository.

Run *npm start* in the terminal.

Allow webcam access when prompted.
